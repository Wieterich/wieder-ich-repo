# WIEDER ICH

> *Du bist mehr als deine Fallakte.* — Investigating what bureaucracy, scarcity, and administrative friction do to people.

- **Live Web Instance:** https://wiederichde.netlify.app/
- **Architecture:** 100% client-side static HTML/CSS/JavaScript (zero backend server, zero database, zero cookies, zero tracking/analytics, and zero affiliation with state agencies).
- **License:** MIT License (see `LICENSE`)

## What It Includes

- **Mechanisms of the System (9 Research Essays):** Sociological, psychological, neurobiological, and behavioral-economic perspectives on depersonalization, occupational stigma, mail avoidance, scarcity math, learned helplessness, isolation, cognitive load, low-wage traps, and zero-buffer risk asymmetry.
- **System Traps & Double Binds (8 Decoders):** Practical breakdowns and strategic navigation notes for bureaucratic friction points (such as EKS income estimates, Vermittlungsbudget rules, health vs. availability binds, cooperation vs. autonomy binds, Ortsabwesenheit, objections/Eilrechtsschutz, Bedarfsgemeinschaft assumptions, and asset verification).
- **Quiet Space (Local-Only Notes):** Voluntary reflection area with local `.txt` export (`wieder-ich-notizen.txt`) and instant clear—processed strictly in browser memory with zero server transmission.
- **Reading Companions & Independent Support:** Curated books and non-state support/advocacy pointers in Germany (e.g., Tacheles e.V., local Erwerbsloseninitiativen, Schuldner- und Insolvenzberatung, Wohlfahrtsverbände).
- **Privacy & Research Transparency:** Self-verifiable zero-network-telemetry note (`F12` -> Network tab) and expanded academic/empirical references.

## Important Disclaimers

WIEDER ICH is an independent civic-tech information and reflection resource. It does **not** provide legal advice, medical/psychotherapeutic treatment, or official government services.

## Local Development & Deployment

No build step or server is required. Open `index.html` directly in any modern browser or host the files on any static web host (such as Netlify, GitHub Pages, or local storage).
